# galaxy-portfolio

Static build of Yamil Josue Moreno's AI & cybersecurity portfolio, redesigned
around galaxies and black holes. Served by GitHub Pages at
https://yamilxmoreno.github.io/galaxy-portfolio/

This repository holds only the exported site (Next.js `output: "export"`).
Space imagery is used under CC BY 4.0: EHT Collaboration; NASA, ESA, CSA,
STScI; NASA, ESA, S. Beckwith (STScI) and the HUDF Team; ESO/S. Brunier.
